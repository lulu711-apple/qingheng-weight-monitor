# 轻衡 · 减重监测

轻衡是一套原创、本地优先的减重监测 PWA，采用原生 HTML、CSS 和 JavaScript 开发。项目仅参考了同类产品应具备的功能结构，没有复制第三方仓库的代码、样式或文案。

## 功能

- 本地用户名和密码登录，可创建多个独立用户
- 年龄、性别、身高、活动水平、当前体重、目标体重和计划周期
- 体重、饮食、饮水、睡眠和运动记录
- 7 天与 30 天体重趋势、习惯概览和周期建议
- 炸鸡、汉堡、奶茶、火锅、烧烤等食物的健康口感替代
- 每日热量与营养估算
- 当前用户研究数据 CSV 导出
- 全部用户 JSON 备份与恢复
- PWA 离线缓存和主屏幕安装
- 适配电脑、安卓和 iPhone 浏览器

## 本地运行

在当前目录打开终端：

```powershell
D:\APP\Runtimes\Python313\python.exe -m http.server 8771 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8771/
```

不要直接双击 `index.html`。网页需要通过 HTTP 或 HTTPS 打开，才能正常使用密码哈希、Service Worker 和离线缓存。

## 数据说明

- 每位用户的数据保存在当前浏览器的本地存储中。
- 不同浏览器、不同设备之间不会自动同步。
- 更换域名后，原域名下的数据不会自动出现在新域名中。
- 建议定期使用“导出全部备份”。
- 密码以加盐摘要保存，但本工具不是医疗系统，不应存放高度敏感信息。

## 部署

本项目为纯静态站点，可直接部署到以下平台：

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel
- 任意支持静态文件访问的服务器

发布时应保证网站使用 HTTPS，以便启用密码哈希、PWA 安装和离线缓存。
